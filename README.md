# 국회 질의 국고실 소관과 안내 챗봇

국회의원이 보낸 **여러 질의(국정감사·청문회 등)를 한 번에 붙여넣으면**, 질의마다 국고실 소관인지 가려내고 국고실 안의 **소관 과를 추천**해 주는 업무 보조 도구입니다. 추천은 참고용이고, **최종 확정은 직원이 합니다.**

> ⚠️ **실습용 시제품입니다.** 과 이름(국고실 12개 과)만 실제이고, 과장 성명·과별 업무·질의 예시는 모두 **가상**입니다. 실제 업무분장표나 실제 질의를 넣지 마세요.

## 주요 기능

- **여러 질의 한 번에 처리** — 번호·줄바꿈으로 나누고, 의원실 원본 질의 번호를 그대로 씁니다. 엑셀에서 복사한 표(번호·소속당·성함·질의)도 붙여넣을 수 있고, `[소속당 성함]` 없이 `국민의힘 홍길동`처럼 써도 의원 정보를 읽습니다.
- **소관 판단과 근거 표시** — 질의마다 국고실 소관 여부를 가리고, 추천 과(최대 3개)와 근거(업무명)·과장 정보·일치도를 보여 줍니다. 여러 과에 걸친 질의는 **주관 과와 관련 과**로 나눕니다. 근거가 없으면 지어내지 않고 "국고실 아님 — 근거 없음, 직원 확인 필요"로 표시합니다.
- **직원이 확정** — 소관과·관련과를 여러 개 고르거나 "한국은행 이첩"처럼 직접 입력할 수 있고, 선택한 질의에 한꺼번에 적용할 수 있습니다.
- **보기 편의** — 표로 보기/카드로 보기, 전체·국고실만·판단 어려움·확인 필요·과별·의원별·직원이 바꾼 질의 등 보기 탭, 비슷한 질의 표시, 글자 크기 조절.
- **엑셀(.xlsx)·복사** — 선택한 질의만, 넣을 칸(질의 번호·소속당·국회의원 이름·질의 내용·소관과·제출여부)을 골라 내보냅니다. 파일은 브라우저 안에서 만들어지며 필터(▼)가 달려 있습니다. 파일 이름과 제목에 행사 종류(국감·청문회 등)가 들어갑니다.
- **작업 임시 저장** — 직원이 누를 때만 그 컴퓨터의 브라우저에 저장합니다.

## 판단 방식 (외부 AI를 쓰지 않습니다)

단어 맞춤 방식의 규칙 기반 판단입니다. 질의와 업무분장표의 업무명을 두 글자 단위로 비교해 점수를 내고, 동의어 사전(`data/duties.json`)으로 일상 표현을 보완합니다. 질의 내용은 **외부 AI나 외부 서비스로 전송되지 않고**, 서버에도 저장하지 않습니다.

- 질의가 서로 다른 주제에 걸쳐 있으면 **먼저 언급한 주제의 과**를 주관 과로 정합니다.
- 같은 주제를 두고 비슷하게 겨루면 **판단 어려움**으로 두고 후보를 보여 줍니다.
- 한계: 사전에 없는 풀어 쓴 표현은 "국고실 아님"으로 나올 수 있습니다. 그런 경우를 줄이려고 약한 근거가 있으면 가장 가까운 과를 힌트로 보여 줍니다.

## 실행 방법

필요한 것: Node.js 20 이상

```bash
npm install
npm run dev      # 개발 서버: http://localhost:3000
npm test         # 자동 시험 (Vitest)
npm run build    # 배포용 빌드
npm run lint     # 코드 검사
```

## 기술 스택

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · ExcelJS · Vitest

## 폴더 구조

| 폴더·파일 | 설명 |
|---|---|
| `app/` | 화면과 서버 코드 (`api/recommend/route.ts`가 판단 API) |
| `components/` | 입력·결과(표/카드)·확정 선택칸 등 화면 부품 |
| `lib/` | 질의 나누기, 판단 로직, 엑셀·복사, 보기 탭, 임시 저장 등 |
| `data/` | 가상 업무분장표(`duties.json`), 정답 포함 가상 질의 28건 |
| `tests/` | 자동 시험 |
| `PRD.md` `PLAN.md` `DESIGN.md` `CHECK.md` | 기획서, 개발 계획, 설계서, 점검 결과 |

## 개인정보·보안

- 질의는 이 앱의 서버(`/api/recommend`)로만 보내고, 서버에는 저장·기록하지 않습니다.
- 입력칸에 개인정보 삭제 안내와 개인정보로 보이는 글(주민번호·전화번호·이메일) 감지 경고가 있습니다.
- 비밀 값(`.env`)은 저장소에 올리지 않습니다. 이 앱은 질의 처리에 API 키가 필요하지 않습니다.
- 이 저장소는 공개이므로 **실제 질의·업무분장표·과장 명단을 넣지 마세요.** 실제로 쓰려면 접근 제한(내부망·로그인 등)과 보안 담당 확인이 먼저 필요합니다. 자세한 점검 내용은 `CHECK.md`를 보세요.
